# Pritom Banik — Portfolio

This is the source code of my personal portfolio website. I'm a final-year Computer Science and
Engineering undergraduate at **Khulna University of Engineering & Technology (KUET)**, interested in
AI, machine learning and computer vision, and I build web apps with the MERN stack. This site is
where I keep everything in one place: who I am, what I've built, what I'm good at, and what I've
been up to lately.

**Live site:** https://pritom-banik.github.io/Portfolio/ 

Built with **React**, **Vite**, **React Router** and **Tailwind CSS**.
